# HAWK-X Rescue HQ

**Status: offline browser mockup using synthetic data.**

Start a local HTTP server from the repository root:

```bash
python -m http.server 8000
```

Open http://localhost:8000/core-hq/

The mockup shows an illustrative 2D mission map, an illustrative 3D projected point cloud, and a human review panel. It does not connect to a real drone or store review decisions. Real coordinates must be verified before plotting detection markers.
